A one-star review of the Moon, in 120 characters or fewer, for the
[make.fun](https://make.fun) competition "The Moon Gets One Star".

## The review

> ★☆☆☆☆ Showed up late, stayed all night, left without a word. The tide is still furious.

87 characters. The Moon showed up late, overstayed all night, left without
a word — and the tide is still furious about it.

## How to run

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` (creating `/output` if needed).
Python standard library only — no third-party dependencies.
